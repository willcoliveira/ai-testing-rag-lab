# Security

This is a lab repository: a small assistant over a fictional policy corpus, with no real users or
data. Security issues in the code, the workflows or the deployed demo are still taken seriously.

Report a vulnerability through GitHub's private vulnerability reporting on this repository
(Security tab, "Report a vulnerability"). Please do not open a public issue for it.

The planted attacks in the corpus (hidden instructions, poisoned documents, fake secrets) are
deliberate test material and are labelled as such in `corpus/SOURCES.md`.
